Thresholds are agreed before outcome review. A KPI improvement alone is not an
earnings claim. Hours freed are not cost removed; faster collections are not
revenue. Record an inconclusive result when the evidence cannot distinguish the
intervention from other causes.

## Stage gates and calendar

| Stage | Planned dates | Required decision and evidence | Actual result / reviewer / version |
|---|---|---|---|
| Readiness | | Meet every applicable entry criterion in the operating pilot plan; agree handling and intervention boundaries | |
| Diagnostic weeks 1–2 | | Reconcile baseline; review first diagnostic and record objections | |
| Diagnostic weeks 3–4 | | Resolve or explain disputes; produce second diagnostic | |
| Diagnostic weeks 5–6 | | Review refreshed evidence; decide stop, revise or authorize bounded intervention | |
| Intervention kickoff, if authorized | | Freeze baseline, cohort, capacity, cost cap, guardrails and exact approved plan | |
| Intervention day 30 / 60 / 100 | | Review evidence, quality, cash and attribution; stop or extend observation when justified | |
| Closeout | | Record decision, unresolved claims and retention disposition | |

The intervention clock begins on its actual authorized kickoff date. It is not
automatically diagnostic week one. Review checkpoints do not promise measurable
financial impact by those dates. Preparation of this worksheet satisfies none
of the entry gates by itself.

Final decision: **unrecorded**. Choose continue, revise, stop or expand only after
review. Record the reason, observed result, residual uncertainty, next accountable
owner and data disposition. Do not turn a simulated receipt into a management
approval or infer publication permission from participation.
