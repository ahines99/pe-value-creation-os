Python 3.12+ and uv. Docker Desktop with Linux containers for the browser workspace. No provider key is needed for the default rules-based showcase.

From a checkout of the reviewed commit
uv sync --frozen --extra dev
uv run pvc demo

# Browser workspace: Docker must be running
python scripts/showcase.py up

The setup command prints the local URL and approver token. Keep that token out of recordings and public artifacts.

What this showcase does and does not establish
  • The local operating demo uses synthetic businesses and outcomes. The separate Progress research case uses public filings and clearly labeled analyst assumptions. No customer savings or investment returns are claimed.
  • The default uses rules. Current live-model acceptance and real-source reconciliation require separate evaluation.
  • Core application/database checks and optional observability-image findings have separate evidence records.
  • AWS deployment, production identity, security review, operational readiness and launch decisions remain in the production roadmap.
